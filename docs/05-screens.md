# 05. 화면 정의 (PRD 8장)

> 원문: [00-prd-full.md](./00-prd-full.md) · 인덱스: [README.md](./README.md)

## 8.1 홈/지도 화면

목적: 방문 현황 확인.
구성: 대한민국 지도, 방문 시·도 표시, 방문 지역 수, 기록한 관광지 수, 최근 기록 카드 목록, 사진 기록 시작 버튼.
상태: 방문 기록 없음 / 있음 / 지도 로딩 중 / 로딩 실패.

## 8.2 사진 선택 화면

목적: 사진 선택 및 기록 생성 시작.
구성: 사진 선택 버튼, 선택 사진 미리보기, EXIF 검사 상태, 위치 정보 없는 사진 안내, 촬영일시 없는 사진 안내.
상태: 미선택 / 선택 완료 / EXIF 검사 중 / GPS 확인 완료 / GPS 없음 / 사진 접근 실패.

## 8.3 관광지 후보 선택 화면

목적: 사진과 연결할 실제 관광지 확정.
구성: 사용자 사진 미리보기, 주변 관광지 후보 목록(관광지명·거리·주소·대표 이미지), 매칭 신뢰도, 직접 검색 버튼.
상태: OpenAPI 호출 중 / 후보 있음 / 후보 없음 / 호출 실패 / 직접 검색 중 / 선택 완료.

## 8.4 기록 카드 상세 화면

목적: 생성된 여행 기록 확인.
구성: 사용자 사진, 관광지명, 방문일시, 주소, 지역, 관광 유형, 관광지 소개, 대표 이미지, 삭제 버튼, 수정 버튼.
상태: 카드 로딩 중 / 표시 완료 / 상세 조회 실패 / 삭제 완료.

## 8.5 기록 목록 화면

목적: 생성한 방문 기록 재확인. P0는 최근 기록 목록 수준, P1에서 필터·그룹화 추가.
구성: 최근 기록 목록(방문일·관광지명·지역·사진 썸네일).

## 8.6 설정 화면

목적: 위치 정보·사진·기록 저장 관련 설정 확인.
구성: 위치 정보 활용 안내, EXIF 사용 안내, 기록 데이터 삭제, 전체 기록 초기화, 개인정보 처리 안내, 약관/개인정보 처리방침 링크.
