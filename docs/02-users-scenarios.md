## 4. 타겟 사용자 및 페르소나

| 페르소나           | 특징                                          | P0 핵심 니즈                                        |
| ------------------ | --------------------------------------------- | --------------------------------------------------- |
| 기록형 여행자      | 사진은 많이 찍지만 여행 기록 정리는 귀찮아함  | 사진만으로 방문 기록을 쉽게 만들고 싶음             |
| 지도 수집형 사용자 | 내가 어디를 다녀왔는지 시각적으로 보고 싶어함 | 방문 지역이 지도에 쌓이는 경험을 원함               |
| 국내 여행 탐색자   | 국내 관광지를 가볍게 기록하고 회고하고 싶어함 | 관광공사 데이터 기반의 신뢰도 있는 장소 정보를 원함 |

- P0 1차 타겟: **기록형 여행자**.
- 지도 수집·미션·추천은 P1 이후 확장.

## 5. P0 핵심 사용자 시나리오

### 5.1 위치 정보가 있는 사진 기록

1. 사용자가 여행 사진을 선택한다.
2. 앱이 EXIF에서 GPS 좌표와 촬영일시를 확인한다.
3. GPS 좌표는 앱 내부에서만 사용하고 서버로 전송하지 않는다.
4. GPS 좌표 기준으로 관광공사 위치 기반 관광정보 OpenAPI를 직접 호출한다.
5. 주변 관광지 후보를 거리순으로 보여준다.
6. 사용자가 후보 중 실제 방문지를 선택한다.
7. 선택 관광지의 contentId로 공통정보/이미지정보/지역정보를 OpenAPI 조회한다.
8. 사용자 사진과 관광공사 데이터를 결합해 기록 카드를 생성한다.
9. 방문 기록을 앱 로컬 저장소에 저장한다.
10. 지도 화면에 해당 지역 방문 스탬프를 반영한다.

### 5.2 위치 정보가 없는 사진 기록

1. 사용자가 위치 정보 없는 사진을 선택한다.
2. 앱이 “이 사진에는 위치 정보가 없습니다” 안내를 표시한다.
3. 사용자가 관광지를 직접 검색하거나 지역을 선택한다.
4. 검색어 기반으로 관광공사 OpenAPI를 호출한다.
5. 사용자가 검색 결과 중 실제 방문지를 선택한다.
6. 선택 관광지 기준으로 기록 카드를 생성한다.

### 5.3 관광지 후보가 없거나 불명확한 경우

1. GPS 기준으로 주변 관광지를 조회한다.
2. 후보가 없으면 검색 반경을 확장하거나 직접 검색을 안내한다.
3. 복수 후보가 있으면 사용자가 직접 선택한다.
4. P0에서는 관광지를 자동 확정하지 않는다.
