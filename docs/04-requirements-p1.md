# 04. 기능 요구사항 - P1 (PRD 7장)

> 원문: [00-prd-full.md](./00-prd-full.md) · 인덱스: [README.md](./README.md)

## 7.1 기록 UX 개선

- 기록 목록 화면 추가
- 날짜별 기록 그룹화
- 방문 지역 필터
- 관광 유형 필터
- 기록 수정/삭제 UX 개선
- 사용자 메모 추가

## 7.2 뱃지/칭호

로컬 기록 기반의 간단한 뱃지/칭호 제공(서버 저장 없이 로컬 계산).

| 조건                    | 뱃지/칭호        |
| ----------------------- | ---------------- |
| 첫 기록 생성            | 첫 발자국        |
| 관광지 5개 기록         | 여행 기록가      |
| 시·도 3개 이상 방문     | 작은 지도 수집가 |
| 같은 지역 3회 이상 기록 | 지역 탐험가      |

## 7.3 추천

복잡한 개인화 추천 엔진은 구현하지 않고 단순 추천 제공:

- 아직 방문하지 않은 시·도 표시
- 최근 기록한 지역과 다른 지역 제안
- 키워드 검색 기반 관광지 탐색
- 관광 유형별 탐색

## 7.4 AI 한 줄 해설

선택적 제공:

- 카드에서 “AI 해설 생성”을 누르면 실행
- 관광공사 OpenAPI 공통정보 기반 생성
- 원할 경우 로컬 기록에 저장 가능
- 사실 정보가 아닌 감성적 보조 문구로 표시

## 7.5 관광공모전 수상작 미션

P1 후보. 진행 전 확인 사항: 수상작 API 실시간 호출 가능 여부, 수상작 이미지/촬영지 데이터 저장 가능 여부, 미션 판정 위치정보 처리 방식, OpenAPI 데이터 가공/저장 정책.

구현 시 제한: 수상작 정보 실시간 호출, 촬영지 목록 화면 표시, 사용자 직접 미션 완료 처리, 자동 위치 판정은 제외하거나 별도 검토.
