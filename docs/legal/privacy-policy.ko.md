# Tripic 개인정보 처리방침

> 배포용 초안입니다. `[대괄호]` 항목을 실제 정보로 교체하고, 배포 빌드의 데이터 흐름과 일치하는지 최종 확인한 뒤 공개해야 합니다.

- 공고일: 2026년 8월 6일
- 시행일: [앱 최초 출시일]

[운영자명 또는 상호](이하 “운영자”)는 Tripic 애플리케이션(이하 “서비스”) 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 이 처리방침은 서비스가 어떤 정보를 어떠한 목적으로 처리하고, 이용자가 자신의 정보를 어떻게 관리할 수 있는지 설명합니다.

## 1. 핵심 안내

| 항목          | 처리 방식                                                                                                                                                                                           |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 회원가입      | 현재 회원가입이나 로그인을 제공하지 않습니다.                                                                                                                                                       |
| 사진          | 이용자가 직접 선택한 사진만 앱에서 처리하며, 사진 원본을 운영자 서버나 한국관광공사 OpenAPI로 전송하지 않습니다.                                                                                    |
| 사진 위치정보 | 선택한 사진에 GPS가 있으면 주변 관광지 후보 검색에 사용합니다. GPS 좌표는 Tripic 운영 서버로 보내거나 로컬 데이터베이스에 저장하지 않지만, 검색을 실행할 때 한국관광공사 OpenAPI로 직접 전송됩니다. |
| 여행 기록     | 사진의 로컬 참조, 관광지 식별자, 방문일시, 지역코드, 메모 등의 기록은 이용자의 기기에 저장됩니다.                                                                                                   |
| 광고·추적     | 현재 맞춤형 광고, 광고 식별자 기반 추적 또는 분석 SDK를 사용하지 않습니다.                                                                                                                          |
| 삭제          | 앱의 설정에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 앱을 삭제하면 앱 전용 저장공간의 기록도 운영체제 정책에 따라 삭제됩니다.                                                               |

## 2. 처리하는 정보, 목적 및 보유기간

서비스는 이용자가 기능을 직접 실행한 경우에 필요한 최소한의 정보만 처리합니다.

| 구분             | 처리 항목                                                                                                  | 처리 목적                            | 처리 근거                                                                               | 처리 및 보유기간                                                                                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 선택한 사진      | 이용자가 선택한 사진, 사진 라이브러리 참조값                                                               | 여행 사진 표시 및 방문 기록 연결     | 이용자의 명시적 선택·동의 및 요청한 서비스 제공                                         | 사진 원본은 이용자의 사진 보관함에 유지되며 운영자 서버에 업로드하지 않습니다. 로컬 참조값은 해당 기록 삭제 또는 앱 삭제 시까지 기기에 저장됩니다.                     |
| 사진 메타데이터  | 촬영일시, GPS 포함 여부, GPS 위도·경도(있는 경우)                                                          | 방문일 추정 및 주변 관광지 후보 검색 | 이용자의 동의. 위치정보법이 적용되는 경우 해당 법령에 따른 별도 동의                    | 촬영일시와 GPS 포함 여부는 기록에 저장될 수 있습니다. GPS 위도·경도는 검색 요청에 필요한 동안 메모리에서 일시 처리하고 Tripic 로컬 데이터베이스에는 저장하지 않습니다. |
| 여행 기록        | 관광지 콘텐츠 ID, 방문일시, 지역·시군구·관광유형 코드, 매칭 방식과 신뢰도, 이용자 확정 여부, 생성·수정일시 | 방문 기록 카드와 여행 지도 제공      | 이용자가 요청한 서비스 제공                                                             | 이용자가 개별 또는 전체 기록을 삭제하거나 앱을 삭제할 때까지 기기에 저장됩니다.                                                                                        |
| 이용자 입력 내용 | 여행 메모, 관광지 검색어                                                                                   | 메모 저장 및 관광지 검색             | 이용자의 명시적 입력·선택 및 요청한 서비스 제공. 외부 전송이 필요한 경우 별도 고지·동의 | 메모는 삭제 시까지 기기에 저장됩니다. 검색어는 검색 응답을 받는 동안 일시 처리하며 별도로 저장하지 않습니다.                                                           |

운영자는 현재 위 정보를 자신의 서버에 수집·저장하지 않습니다. 향후 계정, 클라우드 동기화, 고객 문의, 분석 또는 오류 수집 기능을 추가하는 경우 실제 처리 항목·목적·근거·보유기간을 먼저 확정한 뒤 이 처리방침과 앱 내 동의 절차를 변경합니다.

## 3. 개인정보의 제3자 제공 및 외부 서비스 전송

이용자가 위치정보가 포함된 사진으로 “주변 관광지 찾기” 기능을 실행하면 서비스는 다음 정보를 한국관광공사가 제공하는 TourAPI(OpenAPI)로 직접 전송할 수 있습니다.

- 사진에서 확인한 GPS 위도·경도
- 검색 반경과 검색 조건
- 관광지 검색어 또는 관광지 콘텐츠 ID
- 인터넷 통신 과정에서 통상 수반될 수 있는 IP 주소, 요청 시각, 기기·앱의 통신 정보

전송 목적은 주변 관광지 후보, 관광지 검색 결과 및 상세 정보를 실시간으로 받아 표시하는 것입니다. 사진 원본과 이용자의 로컬 여행 기록은 전송하지 않습니다. 외부 서비스 운영자가 요청 정보를 처리·보유하는 방식은 해당 운영자의 정책이 적용될 수 있습니다.

| 제공받는 자                                    | 제공 목적                                             | 제공 항목                                                                                     | 제공 시점·방법                              | 제공받는 자의 보유기간          |
| ---------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------- |
| 한국관광공사 TourAPI(공공데이터포털 경유 가능) | 위치 주변 관광지 후보와 이용자가 요청한 관광정보 반환 | GPS 위도·경도, 검색 반경·조건, 관광지 검색어 또는 콘텐츠 ID, 통신 과정에서 수반되는 요청 정보 | 이용자가 해당 검색을 실행할 때 HTTPS로 전송 | [TourAPI 운영기관 확인 후 입력] |

이용자는 위 제공에 동의하지 않을 수 있습니다. 이 경우 위치 기반 후보 검색은 이용할 수 없지만, 위치정보를 보내지 않는 직접 검색·지역 선택 기능을 이용할 수 있습니다. 직접 검색에서도 검색어와 콘텐츠 ID는 관광정보 반환을 위해 TourAPI로 전송될 수 있습니다.

## 4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 판매하지 않으며, 이용자의 동의 또는 법령상 근거 없이 제3조에 기재한 범위를 넘어 개인정보를 제3자에게 제공하지 않습니다.

법령에 특별한 규정이 있거나 수사기관 등이 적법한 절차에 따라 요구하는 경우에는 관련 법령이 허용하는 범위에서 정보를 제공할 수 있습니다. 현재 운영자가 보유하는 서버 측 이용자 개인정보는 없습니다.

## 5. 개인정보 처리업무의 위탁 및 국외 이전

현재 운영자는 이용자의 사진, 사진 위치정보 또는 여행 기록 처리업무를 외부 업체에 위탁하거나 국외로 이전하지 않습니다.

배포 이후 호스팅, 오류 수집, 분석, 고객지원 또는 클라우드 동기화 서비스를 도입하는 경우 수탁자, 위탁업무, 이전 국가·시점·방법·항목·목적·보유기간 및 거부 방법을 확인하여 이 처리방침에 반영한 뒤 사용합니다.

## 6. 정보주체와 법정대리인의 권리 및 행사방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

1. 앱에서 개별 방문 기록을 삭제할 수 있습니다.
2. 앱의 설정에서 전체 로컬 기록을 초기화할 수 있습니다.
3. 사진 접근 권한을 기기의 운영체제 설정에서 변경하거나 철회할 수 있습니다.
4. 위치정보가 포함된 사진을 사용하지 않고 직접 검색·선택 기능을 이용할 수 있습니다.
5. 개인정보 처리에 관한 문의, 열람·정정·삭제·처리정지 요청 또는 동의 철회는 제10조의 연락처로 요청할 수 있습니다.

서비스는 현재 계정을 만들거나 운영자 서버에 이용자별 기록을 저장하지 않으므로, 운영자가 원격으로 특정 이용자의 기기 내 기록을 조회하거나 삭제할 수 없습니다. 기기에서 삭제한 기록은 복구되지 않을 수 있습니다.

만 14세 미만 아동의 개인정보를 별도로 수집하는 기능을 제공하게 되는 경우에는 법정대리인의 동의를 받는 등 관련 법령상 절차를 마련합니다.

## 7. 개인정보의 파기

1. GPS 위도·경도는 관광지 후보 요청을 처리한 후 앱 메모리에서 더 이상 사용하지 않으며 로컬 데이터베이스에 저장하지 않습니다.
2. 개별 여행 기록은 이용자가 삭제하면 앱의 로컬 데이터베이스에서 삭제합니다.
3. 전체 초기화를 실행하면 앱의 로컬 여행 기록을 삭제합니다.
4. 앱을 삭제하면 운영체제 정책에 따라 앱 전용 저장공간이 삭제됩니다. 다만 이용자의 사진 보관함에 있는 원본 사진은 Tripic이 삭제하지 않습니다.
5. 법령에 따라 일정 기간 보존해야 하는 정보가 생기는 경우에는 해당 정보와 보존 근거·기간을 별도로 고지하고 다른 목적으로 이용하지 않습니다.

## 8. 자동 수집 장치

현재 서비스는 운영자 서버에서 쿠키, 광고 식별자 또는 유사한 추적 장치를 이용해 이용자를 추적하지 않습니다. 외부 OpenAPI 통신 과정에서는 해당 서비스 운영자가 IP 주소나 요청 기록 등 통신 정보를 처리할 수 있습니다.

## 9. 안전성 확보조치

운영자는 개인정보 보호를 위해 다음과 같은 조치를 적용합니다.

- 사진 원본과 여행 기록을 운영자 서버에 업로드하지 않는 데이터 최소화
- GPS 좌표의 로컬 데이터베이스 저장 금지
- 외부 API 통신 시 HTTPS 적용
- 앱 내부 저장소에 대한 운영체제의 접근통제 활용
- 이용자가 직접 기록을 삭제할 수 있는 기능 제공
- 새 SDK나 외부 서비스 도입 전 데이터 처리 범위 검토

이 처리방침을 변경하는 경우 시행일과 변경 내용을 서비스 내 공지 또는 정책 공개 페이지를 통해 안내합니다. 이용자의 권리에 중대한 영향을 미치는 변경은 관련 법령이 요구하는 기간과 방법에 따라 사전에 알립니다.
